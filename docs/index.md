# Welcome to Rhys' Alright Minecraft.

A simple modpack for magic and engineering. Without blowing up your PC.  
Check [features](https://www.rhys-ree.com/Rhys-Alright-MC/Features/featureList/) for a "how to" for certain mods.  

no. AI was not used to make this.

## Download the modpack.
You should download the version that corresponds with the Minecraft Launcher you use.  
- [Modrinth Edition](https://modrinth.com/modpack/rhys-alright-minecraft-2/)  
My personal recommendation is [*Prism Launcher*](https://prismlauncher.org/).

## Creator's Note
This documentation was initially made for people on my Minecraft server to refer to in the case of them not knowing what to do. I found that in the past, many aren't aware of the mods that are in modpacks, which causes modded worlds to die out rather quickly. Later on, I discovered pathouli (the mod), which allows mod and modpack creators 
to write in-game documentation, which is way more convenient.

### So why does this still exist?
Eventually, this could be useful to some who want to make modpacks. If I do continue to write to the docs.
