# What can you do?
This is a modpack for engineers, magicians and adventurers to come together and create.  
(I made this modpack solely to introduce friends to create mod, magic is included as a gateway drug into it.)  

These mods have been configured to create a balanced experience.


Mods are in **Bold**. Clicking them will send you to the mod page.  
Specific Mod Documentations are below the mod names. They are also Clickable.  

Youtube has many intuitive tutorials for these mods too!

### *A list of mods which need more info to utilize to their full potential*

## Engineering
### [**Create**](https://modrinth.com/mod/create)
*This mod includes descriptions within the inventory* and does not *need* a guide.   
[See Create Guide](https://wiki.createmod.net/)  | [See Create Aeronautics](https://createsimulated.com/)  
Implements technology for automations, vehicles and more.  
Create is love. Create is life.  
There are many compatable mods working with Create:
#### Compatible Mods
1. [ComputerCraft](#computer-craft)
2. [Farmer's Delight](#farmers-delight)

### [**Computer Craft**](https://modrinth.com/mod/cc-tweaked)
[See CC:Tweaked Guide](https://tweaked.cc/)  
Includes computers used for Lua Programming for automations and more.


## Magic

## Food
### [**Farmer's Delight**](https://modrinth.com/mod/farmers-delight)
*This mod includes descriptions within the items menu (Just Enough Items)* and does NOT need a guide.  
Adds yummy (and beneficial) food to the game.


## Social
### **Proximity Voice Chat**
Default configuration button is "V". Use this to change settings for Voice.
No more advanced configuration is needed by the client.  
**Note** *Some VPNs block this from working. They can block certain UDP requests which Voice Chat Relies on.*
