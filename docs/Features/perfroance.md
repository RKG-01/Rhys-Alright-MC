# Performance

## Performance Enchancements  
- **Entity Culling**
    - Disabled entities not currently visible on the screen.
- **Ferrite Core**
    - Optimises Memory Usage.
- **Immediately Fast**
    - Changes how minecraft loads stuff.
- **Lithium**
    - Game physics, mob AI, block ticking, etc.
- **ModernFix**
    - Reduces memory usage, and fixes many bugs.
- **Sodium and Sodium Extra**
    - Reworks Minecraft Render Pipeline + Extra Configuration.
- **BadOptimizations**
    - Reworks Minecraft logic unrelated to Rendering.
- **AttributeFix**
    - Fixes unecessary and optimises Minecraft attrbutes.  

```
Modpack was designed with 16GB DDR4, RTX3060ti, Intel i7 10th Gen.
```

Despite these performance enhancements, minecraft performance stil varies on PCs significantly. Below is a list
of Tips and Tricks to help with lower end PCs.

## Tips and Tricks

### R.A.M. allocations
Make sure to allocation at least 4GB of RAM to the Minecraft Instance.  
Follow your Minecraft Launcher guide on how to achieve this.

### Render Distance
Has a significant impact on Minecraft performance- heavily relies on single-core CPU performance.  
Lower = Higher Performance.

### Shaders
Less intensive shaders come included: Sildurs Vibrant Shaders or Sildurs Enhanced Default. Use **;** to toggle on/off.

### Particle Effects
Pariticles can be reduced and disabled using Sodium Extra in Video Settings.
