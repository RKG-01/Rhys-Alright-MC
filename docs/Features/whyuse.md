# Why R.A.M?
Why *R*hys' *A*lright *M*inecraft?

## Custom Configs
I went through all this trouble so make a working modpack with things I personally enjoy from other modpacks. In order to make this work, however, I needed to manually configure many mods in order for them to work in cohesion with one another.  
This resulted in a pretty alright modpack which I enjoy playing, and I wanted to share it with others.

### Do I make money?
no.  
**This is a hobby project**. As a student, I don't have the resources to maintain this relatively unimportant project for mass consumption. I share this project with friends for a server I host, and thats it. I will maintain it as I deem necessary.  
Nevertheless, if you do choose to use/take inspiration from it, I hope you enjoy it as much as I do. I've spent far too much effort making this, but it was made with ♥.
