**All keybinds can be re-binded in Minecraft Controls Settings.**

# Voice Chat

| Action          | Bind |  Purpose    |
|-------          |----- |--------------|
| Quick Configure | **V**  | Set Audio Devices / Audio Levels |
| Mute            | **C**  | Toggle Mute.   |
